## 🎯 系統架構亮點

1. **雙軌分流設計 (Track Switcher)**
   - **🌸 爸媽易讀版**：溫馨馬卡龍圓角視覺，專注於「解惑、消除抽血恐懼、費用與補助管道」。
   - **🩺 臨床專家版**：收錄神經科、心臟科、腎臟科、眼科之 NGS 適應症 Matrix 與外送 SOP。
2. **AI 知識庫小幫手 (RAG 架構)**
   - 內建王禹期醫師 5 大常規門診 FAQ（費用/補助、報告天數、幼童抽血安全、適應症、空腹規定）。
3. **醫病共享決策 (SDM) 提問小卡**
   - 候診快速勾選 2~3 個疑慮，一鍵生成精美提問卡，支援**「下載至手機相簿」**供進診間出示。
4. **深耕計畫即時成果儀表板**
   - 預設每月 30~40 人次指標追蹤、健康識能提升率 (+36.4%)、門診衛教節省時間 (18.5分)。
   - 支援**「一鍵匯出 Excel (CSV) 結案數據」**。
